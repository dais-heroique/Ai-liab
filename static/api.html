EVALUATE

Small integration.
Clear decision.

The customer API is authenticated with an organization API key. Call it immediately before the consequential action in your own application.

POST /api/v1/actions/evaluate
{
  "agent_id": "finance-prod",
  "action_type": "transfer",
  "amount": 2000,
  "parameters": {
    "currency": "EUR"
  }
}
DECISIONapproved / blocked
01 / CONTROL

Deterministic policies

Configured policy rules are evaluated before the security model. A deterministic block stops the action immediately.

02 / RISK

Risk context

Receive a normalized risk score, breakdown and factors calculated for the requested action.

03 / SECURITY

Security evaluation

If deterministic controls do not block the action, the configured security model reviews the proposed action for operational and security risks.

04 / EVIDENCE

Decision record

Conforva persists the decision and API usage event for the organization so it can be inspected in the product.

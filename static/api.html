API DÉVELOPPEUR

Une API.
Chaque action sous contrôle.

Envoyez une action d'agent à Conforva avant que votre application ne l'exécute. L'API renvoie une décision structurée avec le contexte de risque, les contrôles de règles et le résultat des vérifications applicables.

ÉVALUER

Une intégration simple.
Une décision claire.

L'API client est authentifiée avec une clé liée à votre organisation. Appelez-la juste avant l'action importante dans votre propre application.

POST /api/v1/actions/evaluate
{
  "agent_id": "finance-prod",
  "action_type": "transfer",
  "amount": 2000,
  "parameters": {
    "currency": "EUR"
  }
}
DÉCISIONapproved / blocked
01 / CONTRÔLE

Règles déterministes

Les règles configurées sont appliquées dans le processus de décision. Un blocage par une règle déterministe arrête l'action avant son exécution.

02 / RISQUE

Contexte de risque

Recevez un niveau de risque et les facteurs associés à l'action demandée, selon les contrôles configurés.

03 / VÉRIFICATION

Vérification de sécurité

Lorsque les règles ne bloquent pas l'action, une vérification supplémentaire peut analyser la demande sous l'angle de la sécurité et du contexte opérationnel.

04 / TRACE

Historique de décision

Conforva conserve la décision et l'événement d'utilisation pour votre organisation afin qu'ils puissent être consultés dans le produit.

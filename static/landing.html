QUESTIONS

Les réponses avant l'achat.

Est-ce que Conforva est utile si je ne suis pas technique ?

Oui. Si vous utilisez un chatbot, un assistant IA ou un outil qui peut répondre à vos clients, gérer des réservations, traiter des remboursements ou agir sur vos données, Conforva peut contrôler les actions que vous lui soumettez.

Pourquoi utiliser deux IA ? Est-ce une autorisation supplémentaire ?

Non. La première IA reformule la demande. La seconde vérifie si cette reformulation représente fidèlement la demande originale. Cette seconde IA ne devient pas l'autorité finale : les règles déterministes restent prioritaires. Si la compréhension n'est pas validée, l'action peut être arrêtée plutôt que de continuer sur une interprétation incertaine.

Est-ce que la double vérification ralentit l'action ?

Oui, elle ajoute des appels modèle aux flux qui l'utilisent. La latence réelle dépend des modèles et de l'infrastructure ; nous ne publions pas de chiffre ou de SLA non mesuré. Vous pouvez réserver cette vérification aux actions pour lesquelles elle apporte le plus de valeur.

Que se passe-t-il quand mon budget API est atteint ?

Votre budget inclus se renouvelle chaque mois. Le dashboard permet de suivre la consommation. Avec les règles tarifaires actuelles, une fois le budget atteint, les nouveaux appels API ne sont plus acceptés jusqu'au renouvellement. Pour un usage critique ou à plus grande échelle, contactez-nous afin de discuter d'une configuration adaptée.

Qu'est-ce que je peux retrouver en cas de litige ?

L'historique permet d'inspecter les informations enregistrées pour une décision, notamment l'agent, l'action, la décision et les contrôles exécutés. Les capacités d'export et la conservation contractuelle sont décrites séparément sur la page Conformité et ne sont pas promises au-delà de ce qui est réellement disponible.

Où sont mes données et est-ce compatible avec le RGPD ?

Conforva peut traiter des données personnelles selon ce que votre application lui transmet. L'infrastructure actuelle utilise Vercel pour l'application et Turso pour la base, avec la base actuellement configurée en AWS us-east-1. Consultez la page Conformité avant toute mise en production impliquant des données personnelles afin de vérifier les rôles, les données transmises et les exigences de votre organisation.

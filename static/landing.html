QUESTIONS

Les réponses avant l'achat.

Est-ce que Conforva est utile si je ne suis pas technique ?

Oui. Si vous utilisez un chatbot, un assistant IA ou un outil qui peut répondre à vos clients, gérer des réservations, traiter des remboursements ou agir sur vos données, Conforva peut contrôler les actions que vous lui soumettez.

Pourquoi utiliser deux IA ? Et si elles se trompent toutes les deux ?

La première IA reformule la demande. La seconde vérifie cette reformulation indépendamment. Ce mécanisme n'est pas une garantie contre toutes les erreurs : si la vérification n'est pas validée, le flux peut être bloqué. Il n'y a pas de validation humaine automatique présentée comme solution de secours.

Est-ce que la double vérification ralentit l'action ?

Oui, elle ajoute des appels modèle aux flux qui l'utilisent. La latence dépend des modèles et de l'infrastructure ; Conforva ne publie pas de chiffre ou de SLA non mesuré.

Que se passe-t-il quand mon budget API est épuisé ?

Le budget inclus se renouvelle chaque mois. Une fois épuisé, les appels API sont refusés jusqu'au renouvellement selon les règles actuelles du forfait. Le dashboard permet de suivre la consommation. Aucun dépassement payant n'est actuellement proposé.

Qu'est-ce que je peux prouver en cas de litige ?

L'historique permet d'inspecter les informations enregistrées pour une décision, notamment l'agent, l'action, la décision et les contrôles exécutés. La page Conformité indique précisément ce qui est actuellement disponible et ce qui reste à livrer.
